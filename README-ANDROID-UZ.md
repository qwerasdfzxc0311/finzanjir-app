# FINZANJIR Android

Android ilovasi uchun alohida branch: `finzanjir-android-v1`.

- Native Android: Kotlin + Jetpack Compose.
- Build: GitHub Actions cloud runner, JDK 17 + Gradle 8.9 + Android Gradle Plugin.
- APK: Actions artifact sifatida chiqariladi.
- API kalitlari APK ichiga joylanmaydi.
- FINZANJIR avtomatik bloklash qilmaydi; signal → dalil/qarshi dalil/unknown → Case mezonlari → Human Review tamoyili saqlanadi.
- Hozircha sintetik va konseptual namoyish; bank integratsiyasi yoki production tizimi emas.

Yakuniy funksiyalar va bilimlar bazasi asl konsepsiya ZIP hamda AI ZIP to‘liq tekshirilgach birlashtiriladi.
